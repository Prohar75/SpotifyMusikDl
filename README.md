# Spotify Downloader <img src="https://i.imgur.com/w9Ja83W.png" alt="logo" style="float: right; margin-left: 20px; width: 35px">

Simple **Console App** made to download Spotify music.

> [!NOTE]
> This app doesn't download music dirrectly from spotify.

### **links for tools:**
1. [yt-dlp](https://github.com/yt-dlp/yt-dlp), used to download music from **youtube**.
2. [ffmped](https://ffmpeg.org/), used to save the files.


# Usage

Usage is quiet simple, just start the .exe file and paste link a link of your spotify album/playlist/song. On the next Screen you will see a list of tracks and of list is correct press **yes** to continue, then wait untill the download is completed.
